Hydr8 — Architecture Visualization

Water Refilling Station Operations & AI Management System. Django + HTMX + Alpine.js + Tailwind + PostgreSQL + Redis, with edge-local Gemma 2B AI via WebGPU. Multi-tenant (Company-scoped) back-office for Admin / Staff / Driver roles.

01Deployment Topology

Production stack on a single VPS. Cloudflare fronts Traefik, which routes to Gunicorn workers. PostgreSQL, Redis, and the Django app all run on the same host. AI inference runs entirely in the user's browser.

Stack:
  • Cloudflare → Traefik → Gunicorn — trusts X-Forwarded-Proto/X-Forwarded-For.
  • PostgreSQL — relational integrity for financial data; pg_cron for nightly snapshots.

  • Gemma 2B — prompts never leave the device; system operates normally while model initializes.

Correlation ID

Every request gets a cid that propagates into auditlog.LogEntry.cid and structured logs.

Auto-locks the back-office after idle timeout; PIN re-verification required.

Tenant Scope

Attaches request.company; TenantManager filters all queries by company_id.

Rate Limit

@ratelimit → Ratelimited (403) → handler403 renders friendly HTMX fragment.

04Domain Model — Entity Relationships

Tenant root is Company. Every domain record carries a nullable company_id (NULL = platform-default / superuser scope). The financial core is the Remittance → RemittanceRider → RemittanceRiderProductLine aggregate; customer debt is tracked via CreditLine + CreditPayment.

Canonical Roles

Admin, Staff, Driver — seeded by migration 0008_default_roles_and_permissions.

Permission Helpers

is_back_office(user) → Admin|Staff|superuser. is_admin(user) → Admin|superuser.

Login Lockout

5 failures per (ip, username) → 60s lock. Lives in apps.users.services.

Rate Limit Tiers

Login 10/m · PIN 5/15m · Write 30/m · Read 120/m · Search 60/m — all per user (or ip if unauth).
