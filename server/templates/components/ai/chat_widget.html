{% comment %} Reusable Floating AI Chat Widget — Hydr8 ========================================== A self-contained, draggable floating chat head + conversation panel that can be included on ANY page via: {% include "components/ai/chat_widget.html" %} Features: - Draggable chat head (FAB) — pointer events (mouse + touch). Position persists across page loads via localStorage key "hydr8.chat.fab.pos". - Snaps to the nearest screen edge after drag ends (configurable via `snap_to_edge`, default true). - Click (no drag) opens the conversation panel; drag does NOT open it. - Conversation panel shows exchange of message bubbles using the `chat_message.html` component. Panel opens adjacent to the FAB and repositions automatically based on FAB location. - Panel position auto-flips if it would overflow the viewport. - Optional `greeting` context variable for the first assistant message. - Optional `endpoint` context variable (HTMX URL) for live posting. If not provided, the form falls back to a local echo demo so the UI is fully functional standalone (no backend required). Context variables: - greeting (str) First assistant message. Default: Hydr8 welcome. - endpoint (str) HTMX POST URL for sending messages. Optional. - title (str) Panel header title. Default: "Hydr8 AI Assistant". - snap_to_edge (bool) Snap FAB to nearest edge after drag. Default: true. Design tokens: primary, on-primary, primary-container, tertiary-container, surface-container-lowest, surface-container, outline-variant, on-surface, on-surface-variant, background. No raw hex colors. {% endcomment %}
