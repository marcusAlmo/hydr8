{% comment %} Idle lock-screen overlay. Rendered inside base.html for every authenticated user whose tenant has a non-zero ``lockscreen_timeout_minutes`` SystemConfig value. The Alpine.js component tracks user activity (mouse, keyboard, scroll, touch) and, after the configured idle period, blurs the current page and prompts for the user's PIN. On 3 failed PIN attempts the server logs the user out and the client redirects to the login page — matching the standalone screen-lock page rule. The overlay uses ``backdrop-blur-sm`` + ``bg-black/40`` so the page visuals remain visible (blurred) behind the PIN card, exactly like the products pricing PIN modal. {% endcomment %} {% if user.is_authenticated and lockscreen_timeout_minutes > 0 %}
