{% comment %} Collect modal — rendered via HTMX into #modal-root. Lets the operator record a collection against a single customer, **segmented per rider** so the correct rider receives commission credit for the payment. For each rider who handled transactions for this customer: - Borrowed containers sub-section: one row per outstanding container entry tagged to that rider, with an input for how many were returned. - Accredited items sub-section: one row per open credit line tagged to that rider, with inputs for qty paid and amount paid. - Footer: Cancel, Record Collection. Expects context: - customer: dict (id, name, initials, debt_balance, payable_amount, ...) - rider_groups: list of { rider: { id, name, initials, driver_code }, items: [credit_line|borrowed_entry, ...] } Each item carries a ``rider`` key; items are a mix of credit lines and borrowed entries. The template filters by the presence of ``container_key`` (borrowed entry) vs ``product`` (credit line). {% endcomment %}
