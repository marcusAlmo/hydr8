{% comment %} Record debt modal — rendered via HTMX into #modal-root. Lets the operator record a new credit line (debt) against a customer: - Required: Customer, Product, Quantity credited - Optional override: Unit price (pre-filled from product default) - Footer: Cancel, Record Debt The form POSTs to the ``customers:record_debt_submit`` endpoint. On success the server returns a toast + closes the modal. On validation error an inline error banner is swapped into ``#form-error``. Expects context: - customers: list of { id, name } - products: list of { key, label, unit_price } {% endcomment %}
