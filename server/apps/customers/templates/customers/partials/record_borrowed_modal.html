{% comment %} Record borrowed item modal — rendered via HTMX into #modal-root. Lets the operator record containers borrowed by a customer: - Required: Customer, Container type, Quantity borrowed - Optional: Care of (the user responsible for lending — admin/staff/driver) - Footer: Cancel, Record Borrowed The form POSTs to the ``customers:record_borrowed_submit`` endpoint. On success the server returns a toast + closes the modal. On validation error an inline error banner is swapped into ``#form-error``. Expects context: - customers: list of { id, name } - container_types: list of { key, label } - care_of_users: list of { id, label } {% endcomment %}
