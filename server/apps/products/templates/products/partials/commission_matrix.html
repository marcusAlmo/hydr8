{% comment %} Commission Matrix — per-driver commission rates for each product. Features: - Client-side pagination on rider rows (Alpine.js). - Per-product Global Action: select a product, enter a rate, apply to all riders for THAT product only (not all products — safer than a blanket "apply to everything" action). - "Save Matrix Changes" only appears once the user has modified at least one rate input. Tracks changes via Alpine ``dirty`` flag. - Horizontal scroll hint icon appears when product columns exceed the visible width, signalling that more products exist to the right. Expects context: - product_columns: list of { key, label, border_class } - riders: list of { id, name, initials, avatar_bg, avatar_text, driver_code, rate_cells: [{ product_key, rate }] } - page_size: int — riders per page - rider_count: int — total rider count (pre-pagination) {% endcomment %}
